### 오늘 할 일 진행사항

1\. 필터링 기능 수정(팀원A)

수정 완료

2\. GCP 쿠버네티스 서버 새로 설정하기

프로젝트 발표 때까지 사용하고, 그 이후에 마저 설정하고 이전하기

3\. 회원 비밀번호 초기화 메일링 하도록 추가 구현(HoHoRang)

→ 초기화 화면에서 이메일, 번호 입력하고 인증번호 인증하고 바꾸는 형식으로 구현

인증되면 비밀번호 재설정 하도록 입력 받음

번호, 이메일, 비밀번호 3개 정보로 API를 호출하면,

해당 정보가 있는지 체크하고 인증되었는지 체크한 다음 비밀번호를 재설정함

그리고 다시 로그인 화면으로 리다이렉트

4\. 월간 젤리? 라는 후원금을 사용한 사진 올릴 수 있는 API 구현(HoHoRang)

→ 구현 후, 정기 메일 발송할 때 가져와서 첨부할 수 있도록 수정 완료
