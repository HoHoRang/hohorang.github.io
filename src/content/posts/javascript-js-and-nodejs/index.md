## JavaScript(자바스크립트)란?

과거 웹 브라우저 시장을 지배하고 있던 넷스케이프에서, 웹페이지의 보조적인 기능을 수행하기 위해 **브라우저에서 동작하는 경량 프로그래밍 언어**를 개발한 것이 자바스크립트이다.

초창기에는 웹페이지의 보조적인 기능을 수행하기 위해 한정적인 용도로만 사용되었다.

-   Ajax(Asynchronous JavaScript and XML)

이후 자바스크립트를 이용해서 서버와 브라우저가 비동기 방식으로 데이터를 교환할 수 있는 통신 기능인 Ajax가 등장했다.

이전에는 서버로부터 완전한 HTML 코드를 받아 웹페이지를 매번 렝더링하는 방식으로 작동 했었는데, 변경이 필요없는 부분까지 불필요하게 처음부터 렌더링해야 하는 문제가 있었다.

그런데 Ajax가 등장하면서 서버로부터 필요한 데이터만 전송받아 변경해야 하는 부분만 한정적으로 렌더링하는 방식이 가능해진 것이다. 이를 통해 웹 브라우저에서도 빠른 성능과 부드러운 화면 전환이 가능해졌다.

-   jQuery

이후 jQuery의 등장으로 번거롭던 DOM(Document Object Model)을 쉽게 제어할 수 있게 되었고, 자바스크립트보다 배우기 쉽고 직관적이어서 jQuery를 선호하는 개발자가 늘어나기도 했다.

-   V8 자바스크립트 엔진

Ajax의 등장으로 웹 프로그래밍 언어로써의 성능이 확인된 자바스크립트를 사용하려는 시도가 늘어나게 되었고, 이전보다 더욱 빠르게 작동하는 자바스크립트 엔진이 필요하게 되었다.

구글에서 개발한 V8 자바스크립트 엔진은 빠른 성능을 보여주었고, 자바스크립트는 데스크톱과 유사한 UX를 제공할 수 있는 웹 프로그래밍 언어로 정착하게 되었다.

## nodeJS란?

라이언 달(Ryan Dahl)이 발표한 NodeJS는 구글 V8 자바스크립트 엔진으로 빌드된 자바스크립트 런타임 환경이다.

NodeJS는 브라우저의 자바스크립트 엔진에서만 동작하던 자바스크립트를 브라우저 이외의 환경에서도 동작할 수 있도록 자바스크립트 엔진을 브라우저에서 독립시킨 자바스크립트 실행 환경이다.

NodeJS의 등장으로 자바스크립트는 브라우저를 벗어나 서버 사이드 애플리케이션 개발에서도 사용할 수 있는 언어가 되었다. 프론트엔드와 백엔드 영역에서 자바스크립트를 활용할 수 있다는 점은 언어를 학습하는 시간적 측면에서도 장점이 있다.

또한 웹은 물론 모바일, 서버사이드, 데스크톱, 머신러닝, 로보틱스 환경을 위한 프로그래밍 언어로써도 인기있는 언어가 되었다.
