*JavaScript*

JavaScript가 제공하는 7가지 데이터 타입(숫자, 문자열, 불리언, null, undefined, 심벌, 객체 타입)은 크게 **원시 타입(Primitive Type)**과 **객체 타입(Object/Reference Type)**으로 구분할 수 있다.

원시 타입과 객체 타입은 크게 세 가지 측면에서 다르다.

-   원시 타입은 변경 불가능한 값(immutable value)이지만, 객체(참조) 타입은 변경 가능한 값(mutable value)이다.
-   원시 값을 변수에 할당하면 확보된 메모리 공간에는 실제 값이 저장된다. 객체를 변수에 할당하면 확보된 메모리 공간에는 참조 값이 저장된다.
-   원시 값을 갖는 변수를 다른 변수에 할당하면 원본의 **원시 값이 복사되어 전달**된다.(값에 의한 전달) 객체를 가리키는 변수를 다른 변수에 할당하면 **참조 값이 복사되어 전달**된다.(참조에 의한 전달)

## 원시자료형

### 1. 변경 불가능한 값

원시자료형의 값은 변경 불가능한 값이다. 한번 생성된 원시 값은 읽기 전용으로 변경이 되지 않는다.

변수에 할당하는 값을 변경 불가능하다는 것이 아니고, **원시 값 자체를 변경할 수 없다**는 의미이다.

원시 값을 할당한 변수에 새로운 원시 값을 재할당하면 메모리 공간에 저장되어 있는 이전의 원시 값을 변경하는 것이 아니라, 새로운 메모리 공간을 확보하고 재할당한 원시 값을 저장한 후 변수는 재할당한 원시 값을 가리킨다. 즉, 변수가 가리키는 메모리 공간의 주소가 바뀐다.

### 2. 문자열과 불변성

자바스크립트에서 문자열은 원시자료형이고, 값의 변경이 불가능하다.

```javascript
let str = "aaa";
str = "bbb";
```

“aaa”라는 문자열이 생성되고, 이 문자열이 저장된 메모리 공간을 변수 str이 가리킨다.

두 번째 문이 실행되면 “aaa” 문자열을 수정하는 것이 아니라, 새로운 문자열 “bbb”를 메모리에 생성하고 변수 str은 이 문자열을 가리키게 된다.

```javascript
let str = "aaa";
str[0] = "A";

console.log(str); // aaa
```

문자열은 원시자료형이므로, 코드처럼 일부 문자를 변경하는 것이 불가능하다. 물론 str 변수에 새로운 문자열을 재할당하는 것은 가능하다.

### 3. 값에 의한 전달

```javascript
let aaa = 80;
let bbb = aaa;

console.log(aaa); // 80
console.log(bbb); // 80

aaa = 100;

console.log(aaa); // 100
console.log(bbb); // 80
```

aaa 변수에 숫자값을 할당하고, bbb 변수에 aaa 변수를 할당했다.

aaa 변수는 80이라는 값을 가지고 있으므로, bbb 변수에도 80이라는 값이 할당된다. 이때 새로운 숫자 값 80이 생성되어 bbb 변수에 할당된다.

이처럼 원시 값을 갖는 변수를 할당하면 할당받는 변수는 원시 값이 복사되어 전달된다.

aaa와 bbb 모두 80이라는 값을 가지고 있지만, 두 변수는 서로 다른 메모리 공간에 저장된 별개의 값을 가지고 있다. 그러므로 aaa의 값을 다시 변경하더라도, bbb에 저장된 80이라는 값은 변하지 않는 것이다.

## 참조자료형

참조타입, 혹은 객체타입이라고 한다.

객체는 속성의 개수가 정해져 있지 않고, 추가되거나 삭제될 수 있다. 그렇기 때문에 객체는 원시 값처럼 확보할 메모리 공간을 사전에 정할 수 없다. 브라우저마다 관리하는 방식은 다르겠지만, 원시 값을 할당하는 방식과는 다르게 작동하게 된다.

### 1. 변경 가능한 값

객체(참조) 타입 값은 변경 가능한 값이다.

객체를 할당하면, 객체를 할당한 변수가 기억하는 메모리 주소를 통해 메모리 공간에 접근하면 참조 값(reference value)에 접근할 수 있다. 참조 값은 생성된 객체가 저장된 메모리 공간의 주소다.

원시 값을 할당한 변수의 경우 “변수는 ~라는 값을 가진다”라고 표현하지만, 객체를 할당한 변수의 경우에는 “변수는 객체를 참조하고 있다"라고 표현한다.

원시 값은 변경 불가능한 값이므로 값을 변경하려면 재할당하는 방법 외에는 없다. 하지만 객체는 변경 가능한 값이기 때문에, 재할당하지 않고 객체를 직접 변경할 수 있다. 객체 속성을 추가할 수도, 수정할 수도, 삭제할 수도 있다.

객체는 이러한 구조적 단점으로 인해 부작용이 있는데, **여러 개의 식별자가 하나의 객체를 공유할 수 있다**는 것이다.

### 2. 참조에 의한 전달

```javascript
let person = {
	name: "Lee";
};

let copy = person; // 얕은 복사
```

원본 person 변수를 copy라는 변수에 할당하면, 원본의 참조 값이 복사되어 전달된다.

메모리 상의 구조를 예시로 들어 설명하면 아래와 같다.

```javascript
person => 0x00000F2 => "0x00001332"

0x00001332 => {
                name: "Lee";
              }

person => 0x00000F2 => "0x00001332"
copy => 0x0000524  => "0x00001332"
// person은 0x00001332라는 주소 값을 가지는데, copy에도 이 값이 복사된다.
// 따라서, person과 copy 변수는 모두 0x00001332라는 주소 저장된 동일한 객체를 참조하게 된다.
```

두 변수의 메모리 주소는 다르지만, 동일한 참조 값을 가지고(동일한 객체를 가리킴) 이것은 두 식별자가 하나의 객체를 공유한다는 것을 의미한다. 따라서 원본 혹은 사본 중 어느 한쪽에서 객체를 변경하면 서로 영향을 받는다.
